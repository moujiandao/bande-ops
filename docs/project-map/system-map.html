One app. Three external sources.

The shared spine connects authenticated pages to source mirrors and local operating policy. All external tools are invoked by application code, with separate credentials and trust boundaries.

Two forms of authority.

Amazon and SVD own external facts. Supabase holds rebuildable mirrors plus locally authoritative operational settings, mappings, notes, and archives. A page reads mirrors; a separate privileged sync changes them. Recommendations are computed at read time in the mapped workflow, not persisted as purchase orders. lib/reorder/service.ts::assembleRecommendations

The boundaries that shape the answers

Boundary Consequence Evidence
Unknown vs absent Unreadable required quantities block recommendations. An absent AWD row or absent mapped SVD item contributes zero. Unmapped SVD still blocks. lib/reorder/supply.ts::calculateUsableSupply
Units vs boxes FBA and AWD are units. Only SVD boxes are multiplied by a per-SKU pack size; no global physical-pack default is invented. lib/reorder/supply.ts::toUnits lib/reorder/service.ts::assembleRecommendations
Identity vs privilege loadSessionUser verifies getUser and reads the profile. Missing/unknown roles fall back to staff. Owner is required again for an Ads write. lib/auth/session.ts::loadSessionUser lib/auth/guard.ts::requireOwner
Mode vs readiness AMAZON_USE_FAKE selects fake SP-API and Ads clients. Sandbox flags control real hosts. The banner reads mode flags, not credential validity, connectivity, or SVD status. lib/env/mode.ts::getDataSourceMode
Read-only vs external mutation Planning emits suggestions and drafts. Ads is the only exposed external-write seam, but its real client method throws in this tree. lib/ads/client.ts::AdsApiClient.updateCampaign
Schema vs applied policy Migrations define authenticated read policies on mirrors and service-role writer access. This task inspected SQL, not a running database or deployed RLS. supabase/migrations/0010_live_inventory_reorder.sql::source_sync_state supabase/migrations/0023_shipment_adjustments.sql::shipment_evidence_read
